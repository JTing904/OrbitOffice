# Meeting minutes

Write in the user's language.

## Format
- **Meeting**: title, date, attendees.
- **Decisions**: bullet list; each one a complete sentence that stands on its own.
- **Action items**: table with owner, task, due date. Every item needs an owner; if none was named, write "owner: TBD" and flag it.
- **Open questions**: what still needs an answer, and who will find it.
- **Notes** (optional): only context needed to understand the above.

## Rules
- Lead with decisions and actions, not a transcript.
- Keep each bullet to one line where possible.
- Do not invent decisions that were not made; mark unclear points.
- Save to docs/meetings/<date>-<topic>.md.
