# Competitor analysis

Write in the user's language. Use web search for current facts and cite every source.

## Steps
1. Confirm the user's product and 3-5 competitors (ask if unclear).
2. For each competitor collect: positioning (one sentence), main products and prices, target customers, channels (website, social, marketplaces), recent news or launches, what customers praise and complain about (reviews).
3. Build a comparison table: rows = competitors (plus the user's product), columns = the points above.
4. Write findings: where competitors are strong, where they are weak, gaps nobody covers.
5. End with 3-5 **concrete, actionable** recommendations for the user, each with the reason.

## Rules
- Mark anything you could not verify. Do not invent numbers.
- Note the date of the research; this information changes.
- Save to docs/competitor-analysis-<date>.md.
