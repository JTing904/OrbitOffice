# Content calendar

Write in the user's language.

## Steps
1. Confirm the period (e.g. next 4 weeks), platforms, posting frequency and goals. Ask if missing.
2. Check today's date and any holidays, seasons or events in the period; search the web for current trends if available.
3. Mix content types: educational, product, behind-the-scenes, user stories, interactive. No more than 2 of the same type in a row.
4. Produce a Markdown table: date, weekday, platform, topic (concrete), format (post / video / live), owner, status.
5. Add a short list of 5 backup topics.

## Rules
- Topics must be specific enough to write from ("3 mistakes when applying sunscreen", not "sunscreen tips").
- Save to plan/content-calendar-<start date>.md.
