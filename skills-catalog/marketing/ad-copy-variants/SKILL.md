# Ad copy variants

Write in the user's language.

## Steps
1. Confirm the product, audience, platform and the one action you want (click, buy, sign up).
2. Write **at least 5 variants**, each with a different angle: benefit, pain point, social proof, urgency/offer, curiosity.
3. For each variant: headline, body text, call to action — within the platform's length limits (if unknown, headline under 30 characters, body under 90).
4. Label each variant with its angle and the audience it suits.

## Rules
- Claims must be true and supported by the user's information. No "best", "#1" or guarantees unless the user can prove them.
- Save to drafts/ads-<product>-<date>.md as a table.
