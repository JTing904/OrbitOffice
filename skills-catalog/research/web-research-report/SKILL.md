# Web research report

Write in the user's language. Requires web search.

## Steps
1. Turn the question into 3-5 specific search queries (include the year for anything time-sensitive).
2. Read at least 3 independent sources; prefer official sites, primary data and reputable media over content farms.
3. Cross-check key facts: if sources disagree, say so and show both.
4. Write the report:
   - **Answer first**: 3-5 bullet summary.
   - **Details**: sections by sub-question.
   - **Sources**: numbered list with title, link and publication date; cite them inline as [1], [2].
5. Mark what is fact, what is a source's opinion, and what is your own inference.

## Rules
- Never invent sources, numbers or quotes.
- State today's date and how fresh the information is.
- Save to docs/research/<topic>-<date>.md.
