# Short video script

Write in the user's language.

## Structure
- **Hook (0-3 s)**: a question, a surprising result, or a contrast. It decides whether people keep watching.
- **Body**: one idea per shot; show, don't tell. Keep each spoken line under 15 words.
- **Payoff**: deliver what the hook promised.
- **Call to action**: one clear action (follow, comment, link).

## Format
A Markdown table: shot no., duration, visuals (concrete enough to film), on-screen text, voice-over. Total 30-60 seconds unless told otherwise. Add a line with the suggested caption and 3-5 hashtags.

## Rules
- No exaggerated claims; product facts only from the user or sources.
- Save to scripts/<topic>.md.
