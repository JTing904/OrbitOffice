# SEO blog post

Write in the user's language.

## Steps
1. Agree on **one main keyword** and 3-5 related phrases. If web search is available, look at what the top results cover.
2. **Title** (under 60 characters) containing the keyword; **meta description** (under 155 characters) that promises a concrete benefit.
3. **Structure**: H1 = title; H2 sections that answer the questions searchers ask; short paragraphs; lists and tables where they help.
4. Put the keyword naturally in the first 100 words, one H2, and the conclusion. Never stuff keywords.
5. Add 2-3 internal links (to the user's other pages if known) and cite external sources for facts.
6. End with a short summary and a clear next step.

## Output
A Markdown file with front matter: title, description, keyword, slug. Save under drafts/ or the folder the project uses.
