How it works

1. Describe your team

Tell OrbitOffice what kind of team you need (software, marketing, content, etc.) and the work you want done.

2. AI builds the office

The AI builds the teams and agents, each with a role and instructions. Or start from a ready-made template and edit any agent as a .md file.

3. The team does real work

Agents collaborate, handoff work, ask for clarification when needed, and write real files into your project folder.

Features

Departments in one world

Several departments share a single 3D world, enabling seamless collaboration and context sharing.

Real files and handoffs

Agents write actual files into your folder and hand off work to each other, asking you when input is missing.

Shared brain with skills and connectors

A central knowledge base holds skills (like Claude skills) and one‑click connectors for 33 services (Supabase, Vercel, Notion, etc.).

Your own AI keys or built‑in local AI

Add free API keys from providers (Google Gemini, Groq, etc.) encrypted on your PC, or enable a local open model (Qwen3.5, Gemma 4, Granite) with no key needed.

Permission modes

Choose Manual, Auto, or Full access to control AI autonomy. Publishing always asks for confirmation.

Security team

An attacker tests your project for vulnerabilities (only targets you allow) and a security engineer fixes them.

Works with your AI tools

Turn on the MCP server and Claude Code, Cursor or any MCP client can hand tasks to your OrbitOffice team, wait for the result and read the files they wrote. It only listens on your computer, and approvals stay in OrbitOffice.

claude mcp add --transport http orbitoffice http://127.0.0.1:47821/mcp --header "Authorization: Bearer <your key>"

Copy the exact command from Settings → Permissions.

FAQ

Is OrbitOffice free?

Yes. The app is free and open source (MIT License). You only pay for any external AI API usage if you choose to add your own keys; the built‑in local AI runs at no cost.

Which AI models can I use?

You can add API keys for Google Gemini, NVIDIA NIM, Groq, OpenRouter, any OpenAI‑compatible endpoint, or a local Ollama. The built‑in local AI offers Qwen3.5, Gemma 4, and Granite models that run on your machine without keys.

Is my data safe?

Your files stay on your computer. When you use a cloud AI, what the agents read and write is sent to that AI provider; with the built-in local AI nothing leaves your computer. API keys are stored encrypted on your PC and only sent to their own provider. OrbitOffice has no telemetry.

Windows SmartScreen shows a warning – what should I do?

OrbitOffice is not yet code‑signed, so SmartScreen may flag the installer. Click “More info”, then “Run anyway” to proceed.
