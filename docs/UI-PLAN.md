# MyAIOffice UI 方案

状态：第 1 步（UI 重构）已完成；第 2–4 步（Blender 素材、Electron 外壳、打包）待做。参考：全屏等距 3D 办公室（悬浮团队岛 + 中央共享大脑 + 玻璃 HUD）。

## 1. 框架

- 3D 场景永远铺满窗口，所有界面都是浮在上面的深色玻璃面板。
- 桌面 App：无边框窗口 + 自定义标题栏（仅在 Electron 里显示，浏览器里不显示）。
- 中英文可切换（设置页），默认中文，英文小字标签作为装饰保留。

## 2. 页面

| 页面 | 内容 |
|---|---|
| **办公室**（首页） | 三座团队岛 + 共享大脑。点员工 → 员工面板；点团队名 → 镜头飞到该岛；点大脑 → 大脑页。 |
| **任务** | 待批准（置顶，批准 / 拒绝 / 全部批准）、进行中、已完成；第二个标签是「动态」时间线。 |
| **聊天**（浮窗） | 群聊讨论 + 员工单聊，见下文。 |
| **大脑** | 共享记忆：所有已完成任务的成果。可搜索，按员工 / 团队筛选，点开看详情。 |
| **设置** | 语言、默认权限模式、员工编辑（名字、岗位、颜色、技能）、数据导出 / 清空。 |

### 员工面板（右侧）
岗位、技能、当前状态与任务、最近成果、「派给 TA」按钮（把负责人填进指令栏）。

### 全局组件
- 底部指令栏：权限模式（手动 / 自动 / 完全访问）+ 输入 + 负责人 + 自动交接 + 发送。
- 指令面板 Ctrl+K：派任务、切换页面、跳到员工。
- Toast：任务等批准、任务完成。App 里同时发系统通知。
- 小地图（右下）：点击让镜头飞到对应的岛。
- 快捷键：F11 全屏、Ctrl+K 指令面板、Esc 关闭面板。

### 聊天浮窗（设计稿：[mockups/chat.html](mockups/chat.html)）

独立浮窗，不放在员工面板里。

- 入口：顶栏聊天按钮（带未读数）、快捷键 Ctrl+J、员工面板的「和 TA 聊天」、Ctrl+K。
- 窗口：默认在左侧；可拖动、缩放、最小化（变成右下角胶囊，有未读数）；位置和大小会记住。场景仍可拖动旋转。
- 顶部是"会话切换"：「群聊」+ 每位员工的头像（单聊），红点表示未读。
- **群聊讨论**：用户抛话题（如「我要计划做游戏」），员工按相关度依次发言、互相 @ 接话（每条前有"正在输入"），最后由规划师总结。底部显示谁在输入，并有「停止讨论」。
- **讨论结论卡片**：总结 + 每位员工的建议任务；可逐条「+」加入或「全部转为任务」，遵守权限模式；可「继续讨论」。
- **@ 点名**：输入 @ 弹出员工列表，点名后只有 TA 回答，别人可补充一句。
- **单聊**：每人一份独立记录；员工找错人时会说明并转给对口同事；任务做完，员工在自己的聊天里主动通知并附成果卡片。
- 场景联动：发言的员工 3D 标签显示「发言中」，共享大脑同步脉冲。
- 回答来源可替换：先用模拟讨论（按岗位视角 + 话题关键词），之后可接 Claude Code 或本地模型。
- 与底部指令栏的分工：指令栏 = 直接派活；聊天 = 讨论，结论再转成任务。

## 3. 视觉规则

- 深色玻璃、细线条、发光小圆点；等宽小字做标签；不使用 emoji。
- 团队主色：产品 `#2fbf8f`、质量 `#5b86ff`、工程 `#e0556b`；强调色（岛、面板标记）跟团队色走。
- 状态色：进行中 琥珀、待批准 红、完成 绿、共享大脑 青。

## 4. 已知边界（v1）

- 每座岛固定 2 个工位，员工编辑只能改名字 / 岗位 / 颜色 / 技能，暂不支持新增员工或团队。
- 员工目前是模拟工作，大脑里的"成果"是预设文本；接入真实 AI 后才是真实内容。
- 大脑页的数据 = 已完成任务，存在本机，不联网。

## 5. 实施顺序

1. UI 重构：导航与四个页面、员工面板、i18n、指令面板、Toast、小地图（先在现有 3D 场景上做）。
2. 用 Blender 重做全部 3D 素材（角色、工位、椅子、岛、家具、大脑），导出 GLB。
3. Electron 外壳：无边框标题栏、快捷键、系统通知、托盘。
4. 打包成 Windows 可执行文件。
