# MyAIOffice 功能方案

状态：已实现 = 桌面 App；AI 池（多来源、每家多个模型、体检、按强弱自动选用、出错自动切换）；8 人团队；员工真实执行（看目录 / 搜索 / 读 / 精确修改 / 写文件、运行命令、提问、项目笔记）；员工自己判断（不清楚就问、不该做就停、有问题打回、做完确认是否交接）；岗位只能写职责内的文件；交接需用户批准；聊天里直接对话；任务详情页。未实现 = 群聊多人讨论、connector（MCP）、内置本地 AI、分档与用量显示。

## 1. 目标

员工用真正的 AI 干活：写代码、写报告，产出真实可用的文件。不再是模拟。

## 2. 团队（8 人）

按"做一个项目的步骤"配齐岗位，补上原来缺的设计和开发。

| 团队 | 员工 | 负责的步骤 |
|---|---|---|
| 产品组 | 规划师 | 需求、架构、拆任务 |
| 产品组 | **设计师**（新增） | 界面稿、交互流程 |
| 产品组 | 笔杆 | 文档、报告、更新记录 |
| 工程组 | **开发工程师**（新增） | 写代码 |
| 工程组 | 虫探 | 定位并修 Bug |
| 工程组 | 运维哥 | 打包、部署、回滚预案 |
| 质量组 | 测试员 | 写测试、跑测试 |
| 质量组 | 老审 | 代码审查 |

3D 场景：产品组和工程组的岛各加一个工位（3 + 3 + 2）。

## 3. 工作流（带打回）

```
需求 → 设计 → 拆任务 → 写代码 → 测试 → 审查 → 部署 → 文档
规划师  设计师  规划师    开发     测试员  老审    运维哥  笔杆
                           ↑         │      │
                           └─ 不通过 ─┴──────┘   （Bug 交给虫探，改动交回开发）
```

- 测试不通过 / 审查不通过：自动打回，附上原因。
- 同一个任务最多打回 2 轮，超过就停下来问用户，避免死循环和白白消耗额度。
- 没有界面的项目可以跳过设计这一步。

## 4. AI 池

不绑定某一个 AI。把多个来源放进池子，员工干活时取一个可用的，额度用完自动换下一个。

- **来源**（已实现设置界面）：可添加多个，预设有 NVIDIA NIM、Google Gemini、OpenRouter、Groq、本地 Ollama、自定义；每个来源填 API Key 即可，其余自动完成。
- **分档**：每个来源标成「强」或「轻」。写代码、审查、架构用强的；周报、整理、总结用轻的。
- **切换**：某个来源报额度不足或出错，自动换池子里的下一个，并在动态里记一条。
- **可见**：设置页显示每个来源的状态和今天用了多少次；每个任务记下是哪个来源做的。
- **员工偏好**（可选）：可以给某个员工指定优先用哪个来源。

### 内置本地 AI（后面做）

- 目标：用户一键安装本地 AI，不需要另外装 Ollama。
- 做法：把一个小型开源推理引擎打包进 App（几十 MB，提供 OpenAI 兼容接口），模型文件按需下载，下载完自动加进 AI 池，不用填 Key。
- 界面：列出几个推荐模型，显示大小和适合的用途，点一下下载，带进度条，可删除。
- 限制：模型文件本身要占空间（小模型约 2–3GB）；显存小的电脑只能跑小模型，适合「轻」的用途。
- 待定：用哪个引擎、推荐哪些模型，要在目标电脑上实测后定。

## 5. 项目文件夹与权限

- 用户选一个项目文件夹，员工只能在里面读写，不能碰电脑上别的地方。
- 权限模式变成真的：
  - 手动：每次改文件、跑命令前都问。
  - 自动：读文件和小改动直接做；删除、部署、跑命令要问。
  - 完全访问：都不问。
- 这要求做成桌面 App（网页没有权限调用本机程序和读写文件）。

## 6. 聊天与大脑

- 聊天浮窗接上 AI 池：群聊讨论、单聊、@ 点名、结论一键转成任务。
- 大脑存员工真实写出的内容和关键决定，新任务开始时带上相关记忆。

## 7. 实施顺序

1. 桌面 App 外壳（Electron）：能选项目文件夹，能调用本机程序。
2. AI 池最小版：先接一个来源，让**一位员工**真的在项目文件夹里写出文件。验证可行，看额度消耗。
3. 团队扩到 8 人，3D 场景加工位。
4. 完整工作流 + 打回。
5. AI 池完整版：多来源、分档、自动切换、用量显示。
6. 聊天浮窗和大脑接上真 AI。

## 8. 已定与待定

- **第一个来源：NVIDIA NIM**（用户提供 API Key；没有 Claude API）。
- NIM 是对话接口，模型自己不会读写文件。读文件、写文件、跑命令由 App 实现并按权限模式把关。
- API Key 只保存在本机：App 设置页填写；开发阶段放在被忽略的本地文件里，不进仓库。
- 待定：用哪个模型。接上 Key 后先查账号可用的模型，再选适合写代码的。
- 各家的额度和使用条款会变，接入前要逐个确认。
