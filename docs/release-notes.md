# OrbitOffice v0.1.0 Release Notes

## What is OrbitOffice?
OrbitOffice is a 3D office for your AI team. Describe the work, and a team of AI agents plans it, does it, checks each other's work and hands it on — writing real files in a folder you choose.

## Highlights
- **Build your own AI office**: describe a team in one sentence and the AI builds it, or start from a template
- **Shared brain**: project memory, skills library and skill store, connector store with one-click sign-in.
- **Your own AI**: your own free API keys stored encrypted on your computer, built-in local AI (Qwen3.5, Gemma 4, Granite; no key needed).
- **Permission modes**: Manual, Auto, Full access; publishing always asks.
- **Security team**: an attacker tests your project for vulnerabilities (only targets you allow) and a security engineer fixes them.
- **Multiple departments**: share one 3D world, agents split work and hand off.
- **Works with your AI tools (MCP)**: turn on the MCP server and Claude Code, Cursor or any MCP client can assign tasks to your OrbitOffice team, wait for the result and read the files they wrote. Local only, needs a key, and approvals stay in the app.

## Download and Install
Download the Windows installer from the [GitHub releases page](https://github.com/JTing904/OrbitOffice/releases/latest):
**OrbitOffice-Setup-0.1.0.exe**
Note: The installer is not code-signed yet, so Windows SmartScreen may show a warning. Click **More info**, then **Run anyway**.

## Requirements
- Windows 10/11 64-bit
- Either your own free API key from a provider (Google Gemini, NVIDIA NIM, Groq, OpenRouter, etc.) or the built-in local AI (no key needed).

## Quick Start
1. Run the installer.
2. Open Settings → AI & connections. Either enable Local AI (one click) or add a free API key from a provider.
3. In Settings → General, choose the folder the team should work in.
4. Enter a task in the bottom bar, e.g., "Plan and build a to-do list web page".
